# إصلاح إنشاء أكواد الرصيد والحملات

## الشواهد

- فحص RPC الإنتاجي للقراءة فقط: health بالإصدار 27، وقوائم الأكواد والحملات تعمل؛ لا أكواد رصيد أو حملات محفوظة وقت الفحص.
- حدود الحملة المحفوظة: تشييكة واحدة للعميل، 3 أيام، 30 تفعيلًا، حد منفعة 30 جنيهًا للعميل، ميزانية إجمالية 30 جنيهًا، خصم حتى 30%، رصيد ترويجي حتى 30 جنيهًا.
- هذه الحدود تفسر رفض الحملات التي تتجاوزها. لم تصلنا قيم مسودة المستخدم أو استثناء حفظ كود الرصيد الفعلي؛ لذلك لا نزعم تحديد سبب رفض كود الرصيد بعينه.
- أخطاء الحفظ المختلفة كانت تُحوّل إلى رسالة عامة، مما يمنع المستخدم من تصحيح السبب.

## التعديلات

1. فحص حدود الحملة قبل محاولة الإنشاء وبيان كل حد متجاوز بالعربية.
2. الحفاظ على المسودة عند الرفض وإتاحة تعديل حدود الإدارة ثم العودة إلى العرض ذاته.
3. حفظ البيانات والإجراء نفسه عند فقد تأكيد الاتصال؛ المسودة التي أُرسلت للحفظ تبقى ثابتة عند إعادة المحاولة.
4. الاحتفاظ بحقل الإدخال عند القيمة غير الصالحة بدل فقد مسار المعالج.
5. زر لتوليد كود عشوائي لأكواد الرصيد والحملات، بدون إنشاء التزام مالي قبل الموافقة.
6. حساب إجمالي الرصيد المدفوع وعرضه مع زر يؤكد الاستلام الفعلي، بدل إلزام المستخدم بكتابة الحسبة.
7. توضيح أن عدد الاستخدامات هو عدد حسابات مستبدلي الكود، وليس عدد صفوف الإكسل.
8. تصنيف رسائل رفض قاعدة البيانات المعروفة فقط؛ لا تُعرض الأسرار أو جسم الخطأ الخام، ولا يعيد عميل RPC تنفيذ طلب مالي تلقائيًا.

## التحقق

- 258 اختبار commerce نجح، مع منع الشبكة الخارجية وحذف الملفات.
- حفظ فعلي في PostgreSQL محلي منفصل نجح: كود رصيد محسوب بـ6002 قرش، وحملة واحدة بعد تعديل حدود الاختبار صراحة، وإعادة التأكيد لا تضاعف الإنشاء.
- لم يُنشأ دفع لعميل أو عمولة من عملية إصدار الكود في اختبار القاعدة.
- دليل الاختبار: `acceptance_commerce_code_creation_caa8921fafd2.json`.
- 247 اختبار Telegram نجح، مع منع الشبكة الخارجية وحذف الملفات؛ الدليل `outputs/telegram_audit_20261007/combined_test_results.json`.

## التشغيل

التعديلات في الملفات المحلية. لم نغيّر حدود الإنتاج أو ننشئ أكواد نقدية بإيصالات افتراضية فيه. العملية الموجودة على 5050 بدأت قبل هذه التعديلات؛ إعادة تشغيلها لازمة لتحميلها. استقبال البوت متوقف وقت الفحص، وطابور البرنامج يتضمن ملفًا active وملفات pending. لم نعد تشغيل التطبيق أو نغيّر حالة تلك الملفات أو نفعّل الدفع التلقائي.
