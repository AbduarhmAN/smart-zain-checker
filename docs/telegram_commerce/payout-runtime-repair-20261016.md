# إصلاح تشغيل الصرف النقدي والإشعارات

طُبّقت الترقيتان 36 و37 بموافقة المستخدم على المشروع المحدد، بعد مقارنة بصمات جميع الترقيات السابقة. أكّد التحقق وجود الوظائف الخمس ومنع تنفيذها من حسابات anon وauthenticated. [دليل التطبيق](payout_deployment_20261016.json). تحققت قراءة الأرباح واتصال تلقرام وربط قناة الصرف المحددة، ولا توجد إشعارات تنتظر إعداد القناة. لم تُنشأ عملية صرف تجريبية على الإنتاج.

أصبح بإمكان الإدارة إدخال المبلغ ثم اختيار «نقدًا باليد، دون رقم عملية». ينشأ مرجع داخلي ثابت للمراجعة؛ لا يحدث تسجيل مالي قبل الضغط على التأكيد النهائي. تُرسل رسالة تأكيد الاستلام المعتادة للشريك. أخطاء الحقول تبقي القيم السابقة والمدخل الحالي محفوظين للتصحيح.

تعتمد أسماء الشركاء على أزرار داخل البوت لتجنب BUTTON_USER_INVALID. يؤجَّل ضبط قائمة الأوامر للحساب الذي لا يتعرف عليه تلقرام حتى يراسل البوت؛ لا يجرى تكرار setMyCommands للحساب غير المعروف. تتدرج مهلة إعادة محاولة إشعارات الصرف عند تعذر الشبكة أو غياب وظائف القاعدة، ثم تعود للمهلة الطبيعية عند نجاحها. فشل بناء الرسالة قبل الإرسال قابل لإعادة المحاولة المحدودة، بينما يبقى فشل الرد بعد بدء الإرسال غير مؤكد دون إعادة عمياء.

أُزيلت إعادة المحاولات المخفية من محول HTTP مع الاحتفاظ بسياسة المحاولات الصريحة. يحجب مرشح السجلات توكن تلقرام في روابط تحذيرات المكتبة والاستثناءات. هذا لا يعالج انقطاع مزود الإنترنت، وقد نجح اتصال getMe الفعلي عند التحقق.

نجح اختبار الصرف النقدي عبر معالج تلقرام وقاعدة PostgreSQL معزولة: صرف دقيق بقيمة 0.00001 جنيه، لا تسجيل قبل التأكيد، صرف واحد بعد فقد الرد وإعادة التأكيد، حماية المبالغ المحجوزة الأخرى، وإيصال واحد وإشعاران محفوظان. [دليل الاختبار](cash_payout_acceptance_42eae8c6a806.json). لا يرسل هذا الاختبار رسائل تلقرام فعلية.

نجح 185 اختبارًا دون شبكة لإنشاء الأكواد والتنسيق والأرباح والصرف النقدي والصلاحيات والإشعارات والنقل وإخفاء التوكن في السجلات.

المراجع الفنية: [تعريف PGRST202 وتحديث الذاكرة المؤقتة للمخطط](https://docs.postgrest.org/en/v16/references/errors.html)، [محول HTTP وسياسة إعادة المحاولة في Requests](https://requests.readthedocs.io/en/latest/_modules/requests/adapters/).

تغييرات Python محفوظة في المصدر؛ لم تُعد تشغيل البرنامج العامل من هذه المهمة. يلزم تحميل النسخة الجديدة للاستفادة منها.
