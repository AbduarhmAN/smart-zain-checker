# حدود حساب الشريك

صفة الشريك مستقلة عن صلاحية إدارة البوت. تسجيل حساب كشريك لا يضيفه إلى قائمة الأدمن.

| المجال | صلاحية الشريك |
| --- | --- |
| الأرباح | أرباحه المتاحة والمعلقة والمحجوزة والمسحوبة وإحصاءات إحالته فقط |
| الإحالة | كود إحالته الخاص؛ لا يغير مصدر إحالة عميل قائم |
| السحب | تقديم طلب من أرباحه، متابعة سجله، وتأكيد استلام مدفوعاته أو الاعتراض عليها |
| الحملات | إنشاء خصم من حصته في طلبات الحملة نفسها وإيقاف حملاته فقط، ضمن حدود الإدارة |
| فحص شيتاته | مشاهدة السعر المحدد له ورفع شيتاته ومتابعتها؛ موافقة الإدارة مطلوبة لكل شيت قبل الدفع |
| المحفظة والنتائج والدعم | حسابه وطلباته ونتائجه ومراسلات دعمه فقط |

إدارة الأسعار والنسب والشركاء، إصدار الرصيد المدفوع أو الترويجي للمنصة، اعتماد المدفوعات والسحوبات، أرباح المنصة والشركاء الآخرين، والتحكم العام في السيرفر والطابور تظل خاصة بالأدمن.

يمكن للإدارة بدء صرف أرباح الشريك من قائمته دون انتظار طلب منه: تراجع المبلغ وجهة التحويل والإيصال، ثم تؤكد التسجيل والإرسال. الشريك يراجع الرسالة ويؤكد الاستلام أو يعترض؛ لا يستطيع بدء هذا المسار الإداري أو التأكيد نيابة عن مستلم آخر.

مثال التمويل المعتمد: أصل الطلب 100 جنيه وحصة الشريك 30%؛ إذا منح خصمًا 20%، يدفع العميل 80 جنيهًا، للمنصة 70 جنيهًا وللشريك 10 جنيهات. لا يُسحب الخصم من أرباح سابقة.

تُفحص هوية مرسل Telegram والمحادثة الخاصة قبل توجيه الأزرار، وتُفحص صلاحية الإدارة داخل الإجراءات الحساسة. تعتمد الإجراءات الخاصة بالشريك على هوية المستخدم المتحقق منها؛ لا يمنح إرسال زر إدارة يدويًا صلاحية إضافية.
