# حملة هدية تشيك

صفحة عرض عربية، 11 بوستًا لأسبوع (5 لليوم الأول)، وإعلان عمودي صامت مدته 35 ثانية.

## العرض

أول تشيكتين مجانًا. بعدهما تشيكة مجانية يوميًا حتى نهاية العرض، ومدته أسبوعان. كل تشيكة لشيت واحد حتى 3000 عميل. كلمة الرسالة: **هدية تشيك**.

أُخذ رقم 3000 من رسالة صاحب الخدمة؛ كلمة «ألف» اعتُبرت زائدة. مدة الحملة أسبوعان للجميع، وتنتهي التشيكة اليومية بانتهاء العرض. لم يُحدَّد تاريخ البداية أو النهاية بعد. التنفيذ حسب دور الحجز. هذه حملة ترويجية؛ لا تضيف نظام احتساب العرض إلى محرك الفحص.

## الاستخدام

- صفحة العرض: `index.html`.
- صور البوستات ونصوصها وتصدير الفيديو: `studio.html`.
- افتح صفحة الاستوديو لتغيير كلمة الرسالة، وتحميل البوستات PNG أو ZIP، وحفظ الفيديو في التنسيق الذي يدعمه المتصفح (MP4 أو WebM).
- جميع الخطوط والمكتبات محلية؛ لا يحتاج العرض إلى CDN أثناء التشغيل.
- يمكن فتح الصفحتين مباشرة، أو خدمتهما عبر أي استضافة ملفات ثابتة. تحتاج وظائف الحافظة والفيديو متصفحًا حديثًا، وبعضها يعمل بصورة أفضل عبر HTTPS أو localhost.
- للمعاينة المعزولة مع حفظ نسخة من التصدير في مجلد `exports`، شغّل `python -B preview_server.py` ثم افتح `http://127.0.0.1:5062/studio.html`.
- في برنامج تشيك الحالي يمكن فتح `/static/promo/index.html` و`/static/promo/studio.html` دون تعديل خادم الفحص.

## تنفيذ الإعلان

GSAP 3.15.0 يدير التسلسل الزمني. Canvas يرسم النص العربي والأشكال، وMediaRecorder يسجّل مسار الصورة فقط. لا يوجد صوت أو طلب إذن للميكروفون. JSZip 3.10.2 يجمع الصور ونصوص النشر. مكتبات الطرف الثالث مأخوذة من توزيع npm عبر jsDelivr، وتحتفظ بترويسات حقوقها.

## الجدول

اليوم 1: الهدية، حجم الشيت، التشيكة اليومية، وقت المتابعة، كلمة الحجز.

اليوم 2: التجربة الأولى. اليوم 3: تجهيز عمودي الرقم والمبلغ. اليوم 4: العقود والحسابات والخدمات. اليوم 5: تذكير بالهدية اليومية. اليوم 6: مشاركة العرض مع زميل. اليوم 7: دعوة للبدء.

لا يوجد عداد حجوزات أو شهادات عملاء أو أوقات تسليم مختلقة. الرسومات توضيحية ولا تعرض بيانات حقيقية. يُفعّل العرض مرة واحدة لكل محصّل. تأكّد من تطبيق هذه الشروط تشغيليًا قبل النشر.

## صياغة الحملة للسوق المصري

الافتتاحية: «التشييك واخد وقت المتابعة؟». اللغة مصرية بسيطة تستخدم مصطلحات المحصّلين: شيت، تشييك، متابعة. كل بوست يبدأ بفكرة تخص المحصّل، ثم يوضح العرض أو خطوة البدء. لا تفترض الصياغة أن كل محصّل يقضي عددًا محددًا من الأيام في التشييك، ولا تضمن نتائج مبيعات أو سدادًا مؤكدًا.

يمكن مقارنة افتتاحية الوقت «وراك متابعات؟ الشيت علينا» بافتتاحية العرض «أول تشيكتين مجانًا» عند النشر. الاختيار النهائي يعتمد على عدد رسائل المحصّلين المؤهّلين والطلبات الفعلية، لا على الإعجابات وحدها.

## فيديو 35 ثانية

سبعة مشاهد: المتابعات (0–4)، مراجعة الشيت مع بيانات زين (4–9)، أول تشيكتين مجانًا (9–13)، حد 3000 عميل (13–17)، العرض اليومي ومدته أسبوعان للجميع (17–23)، عمود الرقم والمبلغ واسم العميل الاختياري (23–29)، كلمة ماسنجر وتأكيد الموعد (29–35). الرسومات توضيحية؛ العداد يشرح سعة الشيت ولا يعرض نتائج عملاء حقيقيين.

المؤثرات مرسومة باستخدام Canvas ومتزامنة عبر GSAP: مسح للشيت، علامات تحقق تدريجية، نقل بصري بين الشيت وبيانات الموقع، عداد سعة، تقويم، كتابة رسالة وانتقالات. الفيديو بلا صوت. النسخة الجاهزة: `exports/hadiyat-check-silent-35s.mp4`.

## أربعة فيديوهات إضافية

كل فيديو صامت ومدته 35 ثانية.

- **وقتك للمتابعة**: يركّز على يوم المحصّل: المكالمات والمتابعات، وكيف يساعده تشيك في مراجعة الشيت. الملف: `exports/hadiyat-check-time-35s.mp4`.
- **العرض خطوة بخطوة**: يفصّل أول تشيكتين مجانًا، حد 3000 عميل، التشيكة اليومية ونهاية العرض بعد أسبوعين. الملف: `exports/hadiyat-check-offer-35s.mp4`.
- **جهّز شيتك صح**: دليل لتجهيز الملف: عمود الرقم، عمود المبلغ، أنواع الأرقام واسم العميل الاختياري. الملف: `exports/hadiyat-check-sheet-35s.mp4`.
- **من الرسالة إلى النتيجة**: يشرح رحلة الطلب: كلمة العرض، إرسال الشيت، تأكيد الموعد، المراجعة ثم استلام النتيجة. الملف: `exports/hadiyat-check-journey-35s.mp4`.

في الاستوديو اختر الفيديو للمعاينة أو تعديل كلمة الرسالة والتصدير. زر حفظ الفيديوهات الأربعة يسجلها بالتتابع، فابقِ الصفحة ظاهرة حتى الاكتمال. معرض الفيديوهات يعرض النسخ الجاهزة. الحزمة: `exports/hadiyat-check-4-videos.zip`، والنصوص: `exports/video-captions-ar.md`. النسخ الجاهزة ضُبطت على 35 ثانية و30 إطارًا/ثانية؛ التصدير المباشر من المتصفح قد يختلف ببضع أجزاء من الثانية.
