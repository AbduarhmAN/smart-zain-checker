# مخطط تدفق فحص زين

## ١. معالجة ملف المحصل

```mermaid
flowchart TD
    A([البداية]) --> B[استلام ملف المحصل وتحديد عمود المبلغ والحالات المطلوب فحصها]
    B --> C{عمود المبلغ محدد؟}
    C -- لا --> C1[إيقاف الفحص: خطأ إعدادات]
    C -- نعم --> D[قراءة الصفوف مع أرقامها الأصلية]
    D --> E{الصف ضمن الحالات المطلوبة؟}
    E -- لا --> E1[تسجيله داخليًا بوصفه مستبعدًا] --> E2{صف آخر؟}
    E -- نعم --> F{الحساب والخدمة والمبلغ صالحة؟}
    F -- لا --> F1[إضافة الصف إلى ورقة الأخطاء] --> E2
    F -- نعم --> G[حفظ الصف الصالح] --> E2
    E2 -- نعم --> E
    E2 -- لا --> H{رقم خدمة مكرر؟}
    H -- نعم --> H1{البيانات متعارضة؟}
    H1 -- نعم --> H2[نقل الصفوف المتعارضة إلى الأخطاء] --> I
    H1 -- لا --> H3[إزالة النسخ المتطابقة من الحساب مع حفظ أرقام صفوفها] --> I
    H -- لا --> I[تجميع الصفوف الصالحة برقم الحساب]
    I --> J[اختيار حساب]
    J --> K[فحص كل خدمة تبدأ بـ ٢ برقم الخدمة]
    K --> L{توجد خدمة لا تبدأ بـ ٢؟}
    L -- نعم --> M[فحص رقم الحساب مرة واحدة في زين]
    L -- لا --> N[إخراج نتائج الخدمات المباشرة الموثوقة وأخطائها]
    M --> O{قراءة الحساب موثوقة؟}
    O -- لا --> P[تسجيل خطأ بحث الحساب للخدمات المعتمدة عليه] --> N
    O -- نعم --> Q{اكتمال نطاق الحساب مثبت؟}
    Q -- لا --> R[تسجيل خطأ نطاق الحساب، دون حساب فرق له] --> N
    Q -- نعم --> S[حساب فرق إجمالي الحساب: مجموع الملف ناقص إجمالي زين]
    S --> T[إضافة صف حساب واحد إلى النتائج، دون تكرار فروق خدماته]
    N --> U{الحساب متعدد الخدمات؟}
    T --> U
    U -- نعم --> V[إضافة خدمات الحساب وقراءاتها المتاحة إلى ورقة الحسابات المتعددة]
    U -- لا --> W{حساب آخر؟}
    V --> W
    W -- نعم --> J
    W -- لا --> X[تصدير النتائج والحسابات المتعددة والأخطاء]
    X --> Y([النهاية])
```

## ٢. فحص زين ومعالجة الاستثناءات

```mermaid
flowchart TD
    A([بدء فحص رقم]) --> B{طريقة البحث؟}
    B -- خدمة تبدأ بـ ٢ --> C[فتح مسار الخدمة برقم الخدمة]
    B -- خدمة لا تبدأ بـ ٢ --> D[فتح مسار الحساب برقم الحساب]
    C --> E[التحقق من أن الصفحة تخص الرقم المطلوب]
    D --> E
    E --> F{ما الذي أعاده الموقع؟}
    F -- مبلغ رقمي صريح --> G{القراءة مستقرة؟}
    G -- نعم --> H[حفظ المبلغ ووقت الفحص ونطاقه]
    G -- لا --> I{حد إعادة الفحص متاح؟}
    F -- خانة فارغة --> J[صفر غير مؤكد؛ لا يحسب فرق]
    F -- إعادة توجيه --> K{المسار غير متوقع؟}
    K -- نعم --> I
    K -- لا --> L[خطأ توجيه؛ لا يعد إثبات سداد]
    F -- مهلة أو خطأ صفحة --> I
    F -- مبلغ غير رقمي --> M[خطأ قراءة المبلغ]
    F -- رفض الطلب --> N[إيقاف مؤقت أو جلسة جديدة وفق حد التشغيل]
    N --> I
    I -- نعم --> O[إعادة البحث ضمن الحد المقرر] --> E
    I -- لا --> P[تسجيل الخطأ دون وضع مبلغ زين صفرًا]
    H --> Q([إنهاء الفحص])
    J --> Q
    L --> Q
    M --> Q
    P --> Q
```

## ٣. معنى النتيجة وحدودها

```mermaid
flowchart TD
    A([مبلغ موثوق ونطاق مطابق]) --> B[الفرق = مبلغ الملف − مبلغ زين]
    B --> C{إشارة الفرق؟}
    C -- موجب --> D[انخفاض ظاهر؛ سبب الانخفاض غير مؤكد آليًا]
    C -- صفر أو داخل السماحية --> E[مطابقة حسابية وفق السماحية]
    C -- سالب --> F[زيادة ظاهرة؛ التسوية احتمال يحتاج دليلًا]
    D --> G([عرض النتيجة])
    E --> G
    F --> G
```

**قاعدة الحساب المتعدد:** إجمالي الحساب يخص كل خدماته في زين. لا يُنسب مبلغ الإجمالي إلى خدمة بعينها، ولا يُطرح منه مبلغ خدمة مفحوصة لاستنتاج مبلغ خدمة أخرى، ولا يُضاف فرق الخدمة إلى فرق الحساب.
