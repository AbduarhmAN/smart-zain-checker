# خوارزمية فحص زين

## المدخلات والمخرجات

```text
المدخلات:
    ملف_المحصل
    عمود_المبلغ_المعتمد
    فلتر_الحالات
    اسم_المحصل
    اكتمال_الحساب[رقم_الحساب]   // مثبت أو غير مثبت؛ الافتراضي غير مثبت
    سماحية_المطابقة = 0.20 ريال

المخرجات للمحصل:
    ورقة_النتائج
    ورقة_الحسابات_المتعددة
    ورقة_الأخطاء

محفوظات داخلية:
    كل_محاولات_البحث
    الصفوف_المستبعدة
    كل_القراءات_السابقة_للإعادة
```

## الخوارزمية الرئيسية

```text
إجراء افحص_ملف(ملف_المحصل, الإعدادات):
    النتائج ← قائمة فارغة
    تفاصيل_الحسابات ← قائمة فارغة
    الأخطاء ← قائمة فارغة
    السجل_الداخلي ← قائمة فارغة

    إذا كان عمود_المبلغ_المعتمد غير محدد:
        أوقف العملية بخطأ إعدادات

    الصفوف ← اقرأ ملف_المحصل مع أرقام صفوف Excel الأصلية
    الصفوف_الصالحة ← قائمة فارغة

    لكل صف في الصفوف:
        إذا لم يطابق الصف فلتر_الحالات:
            أضفه إلى السجل_الداخلي بوصف «مستبعد؛ لم يُفحص»
            تابع إلى الصف التالي

        طبّع رقم_الحساب ورقم_الخدمة مع الاحتفاظ بالأصفار الأولى
        مبلغ_الملف ← اقرأ عمود_المبلغ_المعتمد فقط

        إذا كان رقم_الخدمة مفقودًا أو رقم_الحساب مفقودًا
           أو مبلغ_الملف غير صالح:
            أضف الصف إلى الأخطاء مع السبب
            تابع إلى الصف التالي

        أضف الصف إلى الصفوف_الصالحة

    لكل رقم_خدمة مكرر في الصفوف_الصالحة:
        إذا كانت بيانات الصفوف المكررة متعارضة:
            أضف كل الصفوف المتأثرة إلى الأخطاء
            أزلها من الصفوف_الصالحة

    الحسابات ← اجمع الصفوف_الصالحة بحسب رقم_الحساب
    // لا تجمع بحسب اسم العميل؛ ولا تعتبر تكرار الحساب خطأً

    لكل حساب في الحسابات:
        خدمات_مباشرة ← خدمات الحساب التي يبدأ رقمها بـ 2
        خدمات_عبر_الحساب ← خدمات الحساب التي لا يبدأ رقمها بـ 2

        لكل خدمة في خدمات_مباشرة:
            قراءة_الخدمة[الخدمة] ← افحص_مع_إعادة(«محفظة», رقم_الخدمة)

        إذا كانت خدمات_عبر_الحساب غير فارغة:
            قراءة_الحساب ← افحص_مع_إعادة(«رقم حساب», رقم_الحساب)
            // بحث واحد برقم الحساب، مهما تعددت الخدمات غير البادئة بـ 2
        وإلا:
            قراءة_الحساب ← لا_توجد

        إذا كان عدد خدمات الحساب أكبر من 1:
            لكل خدمة في الحساب:
                أضف إلى تفاصيل_الحسابات:
                    رقم_الحساب، اسم_العميل، رقم_الخدمة، صف_Excel،
                    مبلغ_الخدمة_في_الملف،
                    مبلغ_زين_للخدمة إن توفرت قراءة مباشرة موثوقة

        إذا وُجدت قراءة_الحساب وكانت موثوقة:
            إذا كان اكتمال_الحساب[رقم_الحساب] = «مثبت»:
                مجموع_الملف ← مجموع مبالغ جميع خدمات هذا الحساب الداخلة في النطاق
                فرق_الحساب ← مجموع_الملف − مبلغ_زين_للحساب
                أضف صفًا واحدًا للحساب إلى النتائج
                اربط به أرقام صفوف كل خدمات الحساب
                // لا تصدّر فروق الخدمات المباشرة مرة أخرى في ورقة النتائج
            وإلا:
                أضف خطأ «نطاق الحساب غير مكتمل أو غير مثبت»
                للخدمات التي تعتمد على بحث الحساب
                صدّر نتائج الخدمات المباشرة الموثوقة فقط

        وإلا إذا كان البحث بالحساب مطلوبًا وفشل أو لم يعطِ مبلغًا موثوقًا:
            أضف خطأ بحث الحساب للخدمات التي تعتمد عليه
            صدّر نتائج الخدمات المباشرة الموثوقة فقط

        وإلا:  // جميع خدمات الحساب فُحصت مباشرةً
            لكل خدمة في خدمات_مباشرة:
                إذا كانت قراءتها موثوقة:
                    فرق_الخدمة ← مبلغ_الخدمة_في_الملف − مبلغ_زين_للخدمة
                    أضف صف الخدمة إلى النتائج
                وإلا:
                    أضف خطأ الخدمة إلى الأخطاء

    راجع_الاتساق(الصفوف, النتائج, تفاصيل_الحسابات, الأخطاء, السجل_الداخلي)
    صدّر الأوراق الثلاث فقط للمحصل
نهاية الإجراء
```

## خوارزمية فحص رقم واحد

```text
دالة افحص_مع_إعادة(نوع_البحث, رقم_البحث):
    تحقق أن نوع_البحث = «محفظة» أو «رقم حساب»
    افتح رابط النوع الصحيح مستخدمًا رقم_البحث نفسه

    للقراءة الأولى ثم الإعادات المحدودة:
        تحقق أن الصفحة تخص نوع_البحث ورقم_البحث المطلوبين

        إذا رفض الموقع الطلب:
            جرّب الجلسة الجديدة حسب حد التشغيل
            إذا تكرر الرفض: أوقف الطلبات مؤقتًا وأعد «معلق؛ لا نتيجة»

        إذا أعادت الصفحة توجيهًا ولم يظهر مبلغ:
            إن كان التوجيه غير متوقع: أعد مرة ثم أعد خطأ توجيه
            إن صنفه البرنامج «طبيعيًا»: أعد خطأ توجيه بلا إثبات سداد

        إذا انتهت المهلة:
            أعد في الجلسة، ثم في جلسة جديدة ضمن حد التشغيل
            إذا استمرت المهلة: أعد خطأ مهلة بلا مبلغ

        إذا ظهرت رسالة خطأ أو مبلغ غير رقمي:
            أعد خطأ الصفحة أو خطأ المبلغ

        إذا كانت خانة المبلغ فارغة وفسرتها الصفحة صفرًا:
            أعد «صفر غير مؤكد»؛ لا تستعمله في الفرق

        إذا ظهر مبلغ رقمي، بما فيه صفر صريح:
            انتظر استقرار القراءة وتحقق من هوية الصفحة
            إذا تغيّر المبلغ أثناء إعادة فحص الفرق:
                احتفظ بالقراءتين داخليًا واعتمد النهائية المستقرة
            أعد مبلغًا موثوقًا مع وقت القراءة

    أعد خطأ عدم استقرار القراءة
نهاية الدالة
```

## قواعد المقارنة والاستنتاج

```text
إذا كان البحث بالخدمة:
    فرق_الخدمة = مبلغ_ملف_هذه_الخدمة − مبلغ_زين_لهذه_الخدمة

إذا كان البحث بالحساب واكتمل نطاق الملف:
    فرق_الحساب = مجموع_ملف_الحساب − إجمالي_زين_للحساب

إذا لم يكتمل نطاق الحساب أو لم تثبت القراءة:
    لا تحسب فرقًا معتمدًا

إذا ظهر فرق خدمة وفرق حساب للحساب نفسه:
    لا تجمعهما
    لا تطرح مبلغ الخدمة من إجمالي الحساب لتخمين رصيد خدمة أخرى

إذا كان الفرق > 0:
    المعنى العددي = انخفاض ظاهر؛ سبب الانخفاض غير مثبت آليًا

إذا كان الفرق < 0:
    المعنى العددي = زيادة ظاهرة؛ التسوية تحتاج سندًا

إذا كان |الفرق| ≤ سماحية_المطابقة:
    اعتبره مطابقًا وفق سياسة السماحية، مع حفظ الفرق الرقمي الحقيقي

إذا تساوى المبلغان:
    لا تستنتج عدم حدوث دفع سابق؛ ربما قابلته رسوم أو حركة أخرى
```

## الحالات التي يجب أن تنجح بها الخوارزمية

```text
حالة 1: خدمة تبدأ بـ2، ملف 300، زين 180
        ← فحص خدمة؛ فرق +120

حالة 2: حساب فيه خدمة 2401 (ملف 100، زينها 80)
        وخدمة 5402 (ملف 150) وخدمة 0403 (ملف 200)
        وزين للحساب 400
        ← افحص 2401 مباشرة، وابحث برقم الحساب مرة واحدة
        ← فرق الحساب 450 − 400 = +50 إذا ثبت الاكتمال
        ← لا تضف فرق الخدمة +20 إلى +50
        ← لا تستنتج مبلغًا للخدمتين 5402 و0403

حالة 3: حساب فيه خدمتان لا تبدآن بـ2
        ← بحث واحد برقم الحساب، لا بحث بالخدمتين

حالة 4: ملف الحساب غير مكتمل، وزين للحساب يعرض مبلغًا
        ← احتفظ بقراءة الحساب، ولا تصدر فرق حساب معتمدًا

حالة 5: ملف خدمة 0 وزين 250 مع تسوية مذكورة
        ← فرق −250، والتسوية غير مؤكدة حتى يراجع سندها

حالة 6: زين يعرض صفرًا صريحًا مقابل ملف 120
        ← فرق +120، والسبب غير مثبت

حالة 7: خانة زين فارغة أو فشل البحث
        ← خطأ أو صفر غير مؤكد، وليس مبلغ زين 0

حالة 8: إعادة توجيه «طبيعي» أو «غير طبيعي» بلا مبلغ
        ← خطأ، وليس سدادًا مؤكدًا

حالة 9: حساب مكرر بخدمات فريدة
        ← حساب واحد وخدمات متعددة؛ ليس تعارض بيانات

حالة 10: رقم خدمة مكرر ببيانات متعارضة
         ← خطأ لكل الصفوف المتأثرة؛ لا تبدأ البحث بها

حالة 11: الاسم نفسه تحت رقمَي حساب مختلفين
         ← حسابان منفصلان

حالة 12: في المصدر عمودا مبلغ
         ← استعمل العمود المحدد قبل الفحص، لا الأقرب إلى زين
```
